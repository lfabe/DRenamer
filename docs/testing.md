# Проверка Drawing Renamer

## Автоматические тесты

Тесты xUnit выполняются в Release на Windows 11 x64. Тестовые PDF созданы для проекта. `tests/fixtures/generate_scan.py` генерирует кириллический скан, его повёрнутую копию, PDF с контурным текстом и защищённый паролем PDF. Текстовые листы создаются непосредственно тестами.

| Сценарий | Что проверено |
|---|---|
| PDF с текстом | Формы 1 и 2, форматы А4–А0, нестандартный размер, книжная и альбомная ориентация, повороты 0°, 90°, 180°, 270°, многострочное наименование и чтение вручную заданных граф |
| Пользовательский шаблон | Загрузка JSON и распознавание штампа после масштабирования |
| OCR | Русский растровый PDF и его повёрнутая копия, английский текст в векторных контурах, передача результата на подтверждение, нормализация обозначения |
| Несколько листов | Поиск титульного штампа после первого листа, формы 2а и 2б, игнорирование содержимого таблицы на последующих листах групповой спецификации, сохранение разных полных штампов для ручного выбора |
| Ошибки и отмена анализа | Повреждённый PDF, пароль, отменённый токен |
| Пакетное переименование | Недопустимые и занятые имена, дубликаты с разным регистром, отсутствующий исходник, успешная обработка соседнего файла, совпадение байтов после переименования |
| Отмена | Восстановление после повторного открытия журнала, отказ при занятом исходном пути или изменившемся содержимом, повторная попытка после освобождения пути |

## Проверка выпуска

В окне финальной Release-сборки проверены загрузка синтетического скана, предпросмотр штампа без прокрутки, автоматическое и ручное выделение граф, OCR выделенных областей, ручная правка регистра, подтверждение, переименование и восстановление исходного имени. SHA-256 тестовой копии совпал с исходным после обеих операций. Проверено переключение на тёмную тему.

Трассировка .NET host при запуске с `DOTNET_ROOT`, указывающим на отсутствующий каталог, показала загрузку `coreclr.dll` из Release-папки. Windows 11 без установленных компонентов на отдельной машине или в чистой виртуальной машине не проверялась.

## Ограничения

- Поддержка конкретных CAD-экспортов и виртуальных принтеров требует проверки на соответствующих файлах. В тестовом наборе используются синтетические документы.
- Автоматический поиск рассчитан на основные надписи с различимыми границами. На листах с обрывом вертикальной границы штампа, сильным перекосом, обрезкой или нестандартным расположением может потребоваться ручное выделение. Если есть только листы формы 2а или 2б, программа считывает обозначение и предлагает ввести наименование.
- OCR может изменить регистр и перепутать похожие буквы или цифры. Проверьте предложенную пару перед подтверждением.
- PDF с паролем отображаются с диагностикой. Предпросмотр и OCR используют PDFium и ограничены PDF меньше 4 ГиБ. Отмена анализа проверяется между страницами, областями и вызовами нативных библиотек.

# Drawing Renamer

Окно WinUI 3 и модели представления CommunityToolkit.Mvvm управляют очередью, предпросмотром и подтверждением. Библиотека DrawingRenamer.Core содержит координатную модель, чтение PDF, поиск по шаблонам, OCR и операции с файлами. Тесты обращаются к библиотеке напрямую.

## Риски и решения

- Размер штампа зависит от масштаба печати и формата листа. Шаблон задаёт пропорции граф, поиск сверяет линии таблицы и проверяет четыре ориентации. Предполагаемое расположение без геометрического подтверждения даёт только подсказку.
- PdfPig использует начало координат внизу слева, а растровое изображение — вверху слева. Библиотека приводит обе системы к видимому листу с учётом поворота и обрезки.
- Оценка OCR отражает уверенность в чтении символов. Любая пара, полученная с помощью OCR, требует подтверждения. Несовпадающие пары на разных страницах показываются для выбора.
- PDFium использует нативные ресурсы и требует сериализации вызовов. Приложение ограничивает размер растровой области и освобождает ресурсы при ошибках. Tesseract получает только нужные фрагменты.
- Переименование и перенос выполняются через File.Move без перезаписи. В выбранную папку программа по умолчанию сохраняет копии. Копия проверяется по SHA-256 перед размещением под целевым именем. Журнал записывает намерение до операции и результат после неё. Отмена проверяет хеши перед восстановлением перемещённого PDF или удалением копии.
- .NET и Windows App SDK публикуются рядом с приложением. Отдельная папка сохраняет ресурсы WinUI, нативные DLL и языковые модели.

## Порядок реализации

1. Собрать решение с отдельным проектом обработки, проектом WinUI и тестами.
2. Проверить извлечение координат, повороты и чтение вручную выбранных областей.
3. Проверить формы 1 и 2, несколько масштабов, повороты и неоднозначность между листами.
4. Проверить PDFium и Tesseract на растровом документе с кириллицей, включая поворот.
5. Проверить конфликты и ошибки переименования, журнал, отмену и неизменность байтов.
6. Связать интерфейс с библиотекой, опубликовать x64 и проверить содержимое дистрибутива.
